# Governance

The project begins with a lead-maintainer model. Maintainers own research
direction, schema releases, methodology, and final interpretation review.

Contributors may propose studies, experiments, replications, source records,
ontology changes, and tooling. Changes to evidence contracts require maintainer
approval. Workload, runtime, and hardware reviewers can be added through future
governance updates as the contributor base grows.

No contributor, maintainer, vendor, or model/runtime provider bypasses the same
evidence and provenance requirements. Relevant employment, sponsorship, or
vendor relationships must be declared on affected artifacts and pull requests.

Raw accepted evidence is not removed because it is inconvenient or negative.
Invalid evidence is preserved with an explicit invalidation record.
