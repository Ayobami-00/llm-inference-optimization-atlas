# Proposal templates

Choose the proposal matching the intended contribution. Complete it before implementation, validate it
with `atlas proposal validate`, and render it into the corresponding GitHub issue form. Approval fixes
scope; scientific acceptance still depends on the resulting evidence and review.

Use `atlas proposal new study --guided` or `atlas proposal new experiment --guided`
to fill the common fields interactively. After approval, prefer
`atlas contribution start <issue-url>` so issue identity, approval, and scope are
materialized without manual copying.
