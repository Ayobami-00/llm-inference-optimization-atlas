# Reference templates

Templates are reusable starting points for creating canonical artifacts. They live under
`reference/` because they demonstrate how a schema should be instantiated without claiming to
be empirical evidence. Real, executable examples live under `studies/` and follow the ordinary
proposal and review flow.

Template placeholders use angle brackets. `atlas study new`, `atlas experiment new`, and
`atlas proposal new` copy these files and replace identity fields; the source templates are not
themselves validated as accepted artifacts.
