# Research protocols

Protocols define how Atlas evidence is designed, executed, interpreted, and reviewed. They
are normative for accepted evidence unless an experiment records and justifies a deviation.

The `v1` directory is versioned with the V1 schemas. Protocol clarification may be made within
V1; a change that makes previously valid evidence methodologically incompatible requires a new
protocol version and an explicit migration decision.

External publications and official documentation are cited through stable `SRC####` records in
`reference/sources/v1`. A protocol citation explains a rule; it never replaces run evidence.
