# Ontology

The V1 ontology gives stable IDs and definitions to the concepts shared by
schemas, studies, and graph views. It is a controlled vocabulary, not a list of
claims that an optimization always works.

Entries may be added compatibly during V1. Existing meaning is not silently
changed: concepts are deprecated or superseded and linked to replacements.

Expected mechanisms cite external source records. Measured effects cite Atlas
comparisons and findings under `studies/`.
