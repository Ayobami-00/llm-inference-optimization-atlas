# Reference

`reference/` contains the versioned contracts and shared vocabulary used by all
Atlas studies.

- `schemas/` defines machine-valid artifact shapes.
- `ontology/` defines stable inference-engineering concepts and relations.
- `protocols/` defines how evidence is produced and reviewed.
- `sources/` records external papers, documentation, datasets, and specifications.
- `templates/` provides contributor scaffolding.

Reference artifacts explain and constrain studies; they do not contain measured
Atlas evidence.
