# Security Policy

Report vulnerabilities privately through GitHub's security reporting features
when available. Do not open a public issue for an unpatched vulnerability.

## Study safety

- Never commit credentials, tokens, private URLs, personal data, or machine identifiers.
- Model-generated code must execute in a restricted, disposable sandbox.
- Model and dataset downloads require explicit preparation and license review.
- Prefer immutable revisions, checksums, safe tensor formats, and pinned containers.
- Treat contributed scripts, model outputs, datasets, and external documents as untrusted.

Only the current development branch and latest released V1 line receive fixes.
