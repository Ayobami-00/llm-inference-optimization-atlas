# Interactive chat input set

`conversations.jsonl` contains twelve repository-owned synthetic conversations. They include
short, medium, and long request classes, follow-up turns, concrete constraints, and deterministic
topic-keyword checks. They contain no personal data, secrets, or text copied from external
benchmarks.

The records are licensed under Apache-2.0 with the repository. The study fixes their order through
the experiment seeds and records the file SHA-256 in every run.
